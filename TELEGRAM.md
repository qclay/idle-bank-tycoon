# Подключение к Telegram

## Адрес мини-аппа

```
https://qclay.github.io/idle-bank-tycoon/
```

Ссылка постоянная: GitHub Pages отдаёт папку `docs/` из ветки `main`.
После правок нужно `npm run build` и пуш — адрес не меняется. HTTPS есть.

## Настройка бота

1. Открыть **@BotFather**.
2. `/newbot` → имя и username (если бота ещё нет).
3. `/newapp` → выбрать бота → название, описание, картинка 640×360 →
   **Web App URL** = адрес выше.
4. Либо кнопкой меню: `/mybots` → бот → **Bot Settings** → **Menu Button** →
   **Configure menu button** → вставить адрес и подпись.

## Что уже работает внутри Telegram

- `ready()` + `expand()` + `requestFullscreen()` (Bot API ≥ 8.0, на старых версиях
  просто пропускается).
- Свайп вниз не схлопывает окно, включено подтверждение закрытия.
- Цвет шапки, фона и нижней панели под тему игры.
- Отступы берутся из `safeAreaInset` / `contentSafeAreaInset` и пересчитываются
  на `viewportChanged`, `safeAreaChanged`, `contentSafeAreaChanged`, `fullscreenChanged`.
- Профиль игрока из `initDataUnsafe.user` кладётся в сейв как `S.tg`.
- Вибрация через `HapticFeedback`.
- Облачный сейв в `CloudStorage` (режется на части по 3800 байт). Основной сейв —
  локальный; облачный подхватывается, только если он свежее.

## Чего ещё нет

**Оплата звёздами.** Мини-апп — статика, а ссылку на счёт (`createInvoiceLink`)
может выдать только бот. В `js/pay.js` есть константа `PAY_API`: пропишите туда
адрес бэкенда с эндпоинтом `POST /invoice`, и кнопки покупки начнут открывать
счёт через `Telegram.WebApp.openInvoice`. Пока константа пуста, кнопки честно
сообщают, что оплата не подключена, и ничего не выдают.

**Сервер и лидерборд.** Прогресс живёт на устройстве и в CloudStorage. Для рейтингов
и защиты от накрутки понадобится бэкенд с проверкой `initData`.
