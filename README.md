# Пункт выдачи — Idle Tycoon

Telegram Mini App. Изометрический зал пункта выдачи заказов. Персонаж ходит джойстиком
(драг по экрану), выдаёт заказы, носит выручку в кассу и расширяет пункт, вставая на
площадки покупки.

## Механика

- **Ходьба.** Драг в любом месте экрана — джойстик появляется под пальцем. Герой — Spine-скелет
  (утка) с анимациями `Idle`/`Walk`, отзеркаливается по направлению движения.
- **Выдача.** Клиенты приходят через вход и встают в очередь к стойке. Пока за стойкой стоит
  игрок или нанятый оператор — заказ выдают, выручка ложится на стойку.
- **Инкассация.** Игрок подходит к стойке и забирает выручку в тележку (ограничена
  вместимостью), несёт к кассе и сдаёт. Нанятый администратор делает это сам, в том числе офлайн.
- **Расширение.** Встал на площадку — деньги списываются, объект строится: новые стойки выдачи,
  постаматы, апгрейды тележки, кроссовок и кассы. Если на счету пусто, площадка берёт деньги
  из тележки — иначе игрок стоит с полными руками, а покупка не идёт.
- **Зоны.** Четыре постройки с постоянным эффектом на весь бизнес: кофе-точка (поток
  клиентов), примерочные (оплата), сортировка (скорость операторов), погрузка (доход офлайн).
- **Район.** Через дорогу работает конкурент. Раз в неделю считаем, кто выдал больше заказов.
  Соперник берёт темп от вашего и помнит его: бросить игру нельзя — обгонит. За победу
  кристаллы и серия, после поражения он слабеет.
- **Мета.** Ежедневные задания, достижения со ступенями, три вида посылок-наград, бусты,
  оффлайн-доход с растущим потолком, уровень игрока, магазин за звёзды Telegram.

## Запуск

```bash
npm i
npm run build     # собирает в docs/
npm run serve     # http://localhost:8199
```

## Проверки

```bash
npm run smoke     # 23 сквозные проверки игрового цикла
npm run pads      # площадки: подход с 8 сторон к каждой
npm run pay       # оплата площадки со счёта и из рук
npm run route     # дорога до кассы и проходимость узких мест
npm run district  # гонка с конкурентом за район
npm run pace 168 60   # темп развития: что и когда открывается
npm run perf      # рендерер, FPS и время нашего кода в кадре
npm run shot      # скриншоты экранов
npm run action    # кадры в движении: сбор, сдача, покупка
```

## Темп развития

Проверяется `npm run pace <часов> <активных минут в сутки>` — считает экономику по
формулам игры и печатает, когда открывается каждый объект. Целевая кривая при часе
игры в сутки: вторая стойка сразу, третья через 45 минут, четвёртая через 3 часа,
пятая через 12, шестая на четвёртый день, всё вместе — за 4–5 суток.

Две вещи, которые ломали темп и починены:
награды считались от пола в 4/с (втрое выше стартовой экономики, первая посылка
оплачивала полпункта) — теперь от реального дохода; и цена уровня росла почти
вровень с отдачей — теперь заметно быстрее, чтобы уровнями нельзя было заменить
открытие новых объектов.

Замечание про FPS: в headless без GPU браузер рисует софтверно и даёт ~12 кадров.
`npm run perf` поднимает Chromium с реальным GPU — там 57+ FPS, наш JS занимает
около 0.26 мс на кадр.

## Структура

```
js/core.js      изометрия, форматирование
js/balance.js   ВСЕ числа: планировка зала, цены, скорости, награды
js/state.js     состояние и сейв
js/scene.js     Pixi: пол, стены, объекты, актёры, камера
js/actors.js    игрок, клиенты, кассиры, инкассатор
js/game.js      экономика: выдача, площадки, зоны, апгрейды, оффлайн
js/district.js  гонка за район с конкурентом
js/ui.js        HUD, джойстик, подсказки в зале
js/screens.js   окна
css/ui.css      дизайн-система, перенесённая из фермы
```

## Интерфейс

Свой дизайн-язык под маркетплейс: фиолетовый бренд, белые поверхности, плотные кнопки
с нижней кромкой, тёмное стекло поверх сцены, нижний лист вместо окон. Иконки — собственный
SVG-спрайт в `index.html`, без чужих PNG. Все токены в шапке `css/ui.css`.

Почему не деревянные панели фермы: они тянут за собой сказочную ферму и на современной
сцене пункта выдачи читаются как чужеродные. Единый стиль важнее переиспользования.

## Ассеты

Из проекта `farm` остались только персонажи: Spine-утка (игрок) и изометрические спрайты
людей на 4 направления (клиенты и операторы), плюс шрифт Nunito и спрайт монеты для эффектов.
Весь зал — стеллажи с посылками, стойки выдачи, постаматы, касса, паллеты, скамьи — собран
изометрическими примитивами в коде.
