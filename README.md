# Idle Bank Tycoon — 2D

Клон Idle Bank Tycoon на 2D-спрайтах. Telegram Mini App, чистый HTML/CSS/JS без сборки —
папку можно выложить на любой статик-хостинг.

## Что внутри

**Ядро.** Вертикальный разрез банка: 15 отделов, шахта лифта, хранилище внизу.
Конвейер как в Idle Miner: клерки носят деньги от стойки к шахте → лифт везёт вниз →
хранилище превращает наличные в капитал. Любое звено может стать узким местом,
оно подсвечивается красным.

**Прогресс.** Уровни отделов, вехи (доп. клерк / ×2 сумма / ускорение), менеджеры для
автоматизации (работают и офлайн), множители апгрейда x1/x10/x100/MAX, «Улучшить всё».

**Мета.** 10 банков-городов, реновация с акциями, совет директоров (8 постоянных
апгрейдов), ежедневные задания, контракты банка, 10 достижений со ступенями,
7-дневный вход, три вида сейфов, 14 супер-менеджеров с уровнями и слотами,
бусты, оффлайн-доход с растущим потолком, уровень игрока и опыт.

**Telegram.** SDK, полный экран, безопасные зоны, тема, профиль игрока, вибрация,
облачный сейв в CloudStorage (с локальным как основным).

## Запуск

```bash
python3 -m http.server 8199     # затем http://localhost:8199
```

## Инструменты

```bash
npm i                       # playwright для проверок
node tools/smoke.mjs        # сквозной прокликивающий тест (32 проверки)
node tools/sim.mjs 240      # прогон баланса на 4 часа игры
node tools/shot.mjs         # скриншоты всех экранов
```

Все балансные числа — в `js/balance.js`, в остальном коде констант быть не должно.

## Оплата звёздами

`js/pay.js` умеет открывать счёт через `Telegram.WebApp.openInvoice`, но ссылку на счёт
может выдать только бот. Пропишите адрес своего бэкенда в `PAY_API` — до этого кнопки
покупки честно сообщают, что оплата не подключена, и ничего не выдают.

## Ассеты

Спрайты персонажей, сундуков, иконок и шрифт — временные, взяты из проекта `farm`.
Под банковскую тематику их предстоит заменить.
