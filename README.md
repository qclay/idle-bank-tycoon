# Idle Bank Tycoon — изометрия на 2D-спрайтах

Telegram Mini App. Изометрический зал банка, персонаж ходит джойстиком (драг по экрану),
обслуживает клиентов, носит выручку в хранилище и расширяет банк, вставая на площадки покупки.

## Механика

- **Ходьба.** Драг в любом месте экрана — джойстик появляется под пальцем. Герой — Spine-скелет
  (утка) с анимациями `Idle`/`Walk`, отзеркаливается по направлению движения.
- **Обслуживание.** Клиенты приходят через вход и встают в очередь к стойке. Пока за стойкой
  стоит игрок или нанятый кассир — клиента обслуживают, выручка ложится на стойку.
- **Инкассация.** Игрок подходит к стойке и забирает наличные в сумку (ограничена вместимостью),
  несёт к хранилищу и сдаёт — только тогда деньги попадают на счёт. Нанятый инкассатор делает
  это сам, в том числе офлайн.
- **Расширение.** Встал на площадку — деньги списываются, объект строится: новые стойки,
  банкоматы, апгрейды сумки, ботинок и хранилища.
- **Мета.** Ежедневные задания, достижения со ступенями, три вида сейфов, бусты,
  оффлайн-доход с растущим потолком, уровень игрока, магазин золота за звёзды Telegram.

## Запуск

```bash
npm i
npm run build     # собирает в docs/
npm run serve     # http://localhost:8199
```

## Проверки

```bash
npm run smoke     # 23 сквозные проверки игрового цикла
npm run shot      # скриншоты всех экранов
```

## Структура

```
js/core.js      изометрия, форматирование
js/balance.js   ВСЕ числа: планировка зала, цены, скорости, награды
js/state.js     состояние и сейв
js/scene.js     Pixi: пол, стены, объекты, актёры, камера
js/actors.js    игрок, клиенты, кассиры, инкассатор
js/game.js      экономика: обслуживание, площадки, апгрейды, оффлайн
js/ui.js        HUD, джойстик, подсказки в зале
js/screens.js   окна
css/ui.css      дизайн-система, перенесённая из фермы
```

## Интерфейс

Собран по эталону вольера из проекта фермы: те же токены (`--du`, палитра `#794810` /
`#EAC788` / `#F5E1BA`), деревянная вывеска-шапка, крестик, кнопки `.pup`/`.pen__capbtn`,
иконки — только PNG из ассетов, без эмодзи и самодельных градиентов.

## Ассеты

Временные, из проекта `farm`: Spine-утка, изометрические спрайты людей (4 направления),
панели, кнопки, сундуки, иконки, шрифт Nunito. Сам зал (пол, стены, стойки, сейф, банкоматы)
собран изометрическими примитивами в коде — тем же способом, что и арт фермы в `iso.js`.
